  --summary <short-review-goal> \
  [--cwd <path>] \

  [--review-id <id>] \
  [--dry-run]

Acceptance criteria

  • Create review request files under `reviews/` atomically.
  • Append pending entries to `LIMUX_REVIEW_LEDGER.md` without rewriting prior entries.
  • Print the prompt for the reviewer.
  • Refuse existing request files, leaf symlink/non-regular ledger and review output targets, and overlapping request/ledger paths. Use trusted output directories; parent path components are not recursively audited for symlinks.
  • Reject generated prompt control characters.
  • Document no-secrets and no-raw-transcript rules.
