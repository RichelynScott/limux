Recommended Policy

  1. Use verified .deb releases for normal installs.
  2. Use local source builds for fork-only changes.
  3. Keep WebKitGTK updated through distro security packages.
  4. Avoid curl | bash install paths.
  5. Approve scanner/tool installs separately before using cargo-audit or cargo-deny.
